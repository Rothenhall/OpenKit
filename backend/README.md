# Openkit

Backend for Rothenhall's free tools, built to bring traffic and goodwill to Rothenhall
Partners. NestJS, TypeScript, backend only.

First tool planned: a Sarvam AI agent.

Full context, structure and rules: [AGENTS.md](AGENTS.md).

## Run

```bash
npm install
npm run start:dev
```

Set `PORT` to change the default port 3000.
